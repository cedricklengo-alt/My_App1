 v1.7.2 — RESET PIN : PROTOCOLE DE SECURITE STRICT 🔐
============================================================
Le PIN ne peut etre reinitialise QUE par la personne habilitee :
 1. etre connecte sur l'appareil (jeton du compte exige), ET
 2. recevoir un code SMS dedie sur la SIM du compte ;
 3. code valable 5 min, usage unique, 3 essais maximum ;
 4. 3 codes faux -> reinitialisation BLOQUEE 30 minutes ;
 5. le code n'apparait JAMAIS dans l'app ni dans la reponse API
    (en mode demo : visible uniquement dans les logs du serveur,
     Render -> Logs, ligne « 🔐 [SECURITE] Code reinitialisation ») ;
 6. apres un reset, le titulaire recoit une notification d'alerte.
Protocole teste 13/13 (faux codes, blocage, rejeu, sans jeton).
⚠️ REDEPLOYER LE BACKEND (mbote-backend-deploy.zip) : les routes
   /auth/pin-reset/* sont cote serveur !

============================================================

Comme WhatsApp : si l'app MboteCall est fermée, une notification
« 📞 Appel MboteCall — X t'appelle » s'affiche. On la touche,
l'app s'ouvre, ça sonne, on décroche.

⚠️ 3 PETITES MODIFICATIONS GRADLE A FAIRE UNE FOIS (voir plus bas
   la section « BRANCHEMENT FIREBASE ») + redeployer Render avec
   la variable FIREBASE_SERVICE_ACCOUNT.

Ce paquet contient déjà :
  - android/app/google-services.json  (ta clé Firebase app — incluse !)
  - la permission notifications dans AndroidManifest.xml
  - lib/push.dart + tout le code app (v1.6.0+5)

------------------------------------------------------------
 BRANCHEMENT FIREBASE (3 modifications, 5 minutes)
------------------------------------------------------------

1) Ouvre  C:\dev\mbote\mbote_app\android\settings.gradle.kts
   Dans le bloc  plugins { ... }  (celui qui contient deja
   "com.android.application"), AJOUTE cette ligne :

   id("com.google.gms.google-services") version "4.5.0" apply false

2) Ouvre  C:\dev\mbote\mbote_app\android\app\build.gradle.kts
   Dans le bloc  plugins { ... }  en haut, AJOUTE :

   id("com.google.gms.google-services")

3) Verifie que le fichier
   C:\dev\mbote\mbote_app\android\app\google-services.json
   existe apres extraction du zip (il est fourni dedans).

Puis :  flutter clean  puis  flutter pub get  puis  flutter run

------------------------------------------------------------
 COTE SERVEUR (OBLIGATOIRE pour que ca marche)
------------------------------------------------------------
1) Pousser le nouveau backend sur GitHub + Manual Deploy Render
2) Render > Environment > Add variable :
     Nom    : FIREBASE_SERVICE_ACCOUNT
     Valeur : TOUT le contenu du fichier clé privée
              mbotecall-xxxxx.json (le fichier n°2 SECRET)
3) Au redemarrage, le log Render doit afficher :
     🔔 Notifications push Firebase prêtes (appels app fermée)
